# RAG Evaluation Metrics

This project investigates and compares evaluation metrics for
Retrieval-Augmented Generation (RAG) systems using the RAGTruth dataset.

## Project Structure

- `notebooks/` - Experiment and analysis notebooks
- `src/` - Reusable Python code
- `data/` - Local dataset references
- `results/` - Experimental results and visualizations
- `requirements.txt` - Python dependencies

## Dataset

RAGTruth is used as the primary dataset for evaluating RAG responses.

## Environments

Development and CPU testing:
- VS Code

GPU-based experiments:
- Kaggle
